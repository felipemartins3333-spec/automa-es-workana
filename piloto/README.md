## Conteúdo desta pasta

- `dc/pagina09_abertura.dc.html` — Página 9, abertura "Formação em Radiologia" (PRESERVAR).
- `dc/pagina16_artigo.dc.html` — Página 16, artigo "IA e Ressonância Magnética" (REFINAR — quebra de parede de texto).
- `dc/pagina29_dados.dc.html` — Página 29, "Inspeções em Foco" (REESTRUTURAR — paleta de dados unificada).
